## 批量更改拓展名

1、切换目录
输入 cd 或 cd /d 切换目录，这是基础所以不再赘述

2、使用 ren关键字 批量修改目录下的文件扩展名（后缀）
(1) 为全部文件修改扩展名的方法：

```c
ren * *.zip
```
作用：修改全部文件（无论是否有扩展名） 为 .zip文件

(2) 为全部特定格式的文件修改扩展名的方法：
```c
ren *.dat *.zip
```
作用：修改 .dat文件 为 .zip文件

(3) 为全部文件添加扩展名（原扩展名保留）的方法：
```c
ren *.* *.*.zip
```

## Python之文件处理-批量修改md文档内容
```python
import os
import re
import time


def modify_md_content(top):
    for root, dirs, files in os.walk(top, topdown=False):
        # 循环文件
        for file_name in files:
            file_name_split = file_name.split('.')

            try:
                if file_name_split[-1] == 'md':
                    # 找到md文件并且复制一份md文件路径
                    md_file_path = os.path.join(root, '.'.join(file_name_split))
                    copy_md_file_path = os.path.join(root, '.'.join([f'{file_name_split[0]}_copy', file_name_split[1]]))

                    # 打开md文件然后进行替换
                    with open(md_file_path, 'r', encoding='utf8') as fr, \
                            open(copy_md_file_path, 'w', encoding='utf8') as fw:
                        data = fr.read()
                        # data = re.sub('\(/配图/', '(配图/', data)
                        # data = re.sub('<br>', '<br>\n', data)
                        # data = re.sub('<br>', '', data)
                        data = re.sub('^ #.*? ', '', data)

                        fw.write(data)  # 新文件一次性写入原文件内容
                        # fw.flush()

                    # 删除原文件
                    os.remove(md_file_path)
                    # 重命名新文件名为原文件名
                    os.rename(copy_md_file_path, md_file_path)
                    print(f'{md_file_path} done...')
                    time.sleep(0.5)
            except FileNotFoundError as e:
                print(e)
        time.sleep(0.5)


if __name__ == '__main__':
    top = r'/Users/mac/Desktop/'
    modify_md_content(top)
```

## Google 高级搜索选项

# 优化网络搜索

您可以在搜索中使用符号或词来使搜索结果更加精确。

- Google 搜索通常会忽略不属于搜索运算符的标点符号。
- 不要在符号或单词与您的搜索词之间放置空格。搜索`**site:nytimes.com** `将起作用，但`**site: nytimes.com**` 不会。

## 优化图像搜索

#### 整体高级搜索

1. 转到[高级图像搜索](https://google.com/advanced_image_search)。
2. 使用区域或文件类型等过滤器来缩小结果范围。
3. 在底部，单击 **高级搜索**。

#### 搜索准确的图像尺寸

在您要查找的单词之后，添加文本`imagesize:widthxheight`。确保以像素为单位添加尺寸。

**例子：** `imagesize:500x400`

## 常见的搜索技术

### 搜索社交媒体

放在`**@**`一个词前面搜索社交媒体。例如：`**@twitter**`。

### 搜索价格

放在`**$** `数字前面。例如：`**camera $400**`。

### 搜索主题标签

放在`**#** `一个词的前面。例如：`**#throwbackthursday**`

### 从搜索中排除字词

放在`**-**` 一个你想省略的词前面。例如，`**jaguar speed -car**`

### 搜索完全匹配

将单词或短语放在引号内。例如，`**"tallest building"**`。

### 在一个数字范围内搜索

放在`**..** `两个数字之间。例如，`**camera $50..$100**`。

### 合并搜索

`**OR**`在每个搜索查询之间放置“ ”。例如， `**marathon OR race**`。

### 搜索特定站点

将“ `**site:**`”放在站点或域的前面。例如，`**site:youtube.com** `或 `**site:.gov**`。

### 搜索相关网站

将“ `**related:**`”放在您已经知道的网址前面。例如，`**related:time.com**`。

### 查看 Google 的网站缓存版本

在网站地址前加上“ `**cache:**`”。

**重要提示****：**并非所有搜索运算符都会返回详尽的结果。
