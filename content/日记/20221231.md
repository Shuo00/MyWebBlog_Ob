今天晚上我准备换一下字体
- Typora
- 手机

>[!note]
打开手机系统设置→显示→字体样式→字体，随便找一个免费字体下载（比如：方正兰亭黑Pro），记住字体名称。
打开手机找到目录：内部存储\Huawei\Themes\HWFonts，把刚才下载的苹方黑体拷贝到此目录，然后选择刚才下载的字体ttf文件（比如：方正兰亭黑Pro，文件名：FZLTpro.ttf）删除，把苹方黑体重命名为刚才删除的字体名。
打开手机系统设置→显示→字体样式→我的→我的字体，选中方正兰亭黑Pro。大功告成！整个系统字体比原先好看百倍！

mono等宽字体

>在传统西文印刷中，比例字体可以提高单词的可读性。但因早期的[电脑显示器](https://baike.baidu.com/item/%E7%94%B5%E8%84%91%E6%98%BE%E7%A4%BA%E5%99%A8?fromModule=lemma_inlink)、[打字机](https://baike.baidu.com/item/%E6%89%93%E5%AD%97%E6%9C%BA?fromModule=lemma_inlink)，由于技术的局限，无法进行字母宽度的比例调整，因此将每个字元都制作成一样的宽度，从而形成了等宽字体。在等宽字体中，字母i、j显得两侧空白较多，而字母w、m等的笔画显得相当拥挤。

切换单双拼的脚本
```batch
@echo off

set Mainkey=HKCU\SOFTWARE\Microsoft\InputMethod\Settings\CHS
for /f %%i in ('reg query %MainKey% /v "Enable Double Pinyin" ^| findstr /i "0x1"') do (set flg=%%i)
if not defined flg (
    reg add %MainKey% /v "Enable Double Pinyin" /t REG_DWORD /d 0x1 /f
    echo 已经切换到双拼
    (echo 已经切换到双拼
    echo 5秒后自动关闭)|msg %username% /time:5
) else (
    reg add %MainKey% /v "Enable Double Pinyin" /t REG_DWORD /d 0x0 /f
    (echo 已经切换到全拼
    echo 5秒后自动关闭)|msg %username% /time:5
)
```
