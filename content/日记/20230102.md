最终代码
```cmd
@ECHO OFF

REM 在命令行窗口纯净的输出

for /l %%i in (300,-1,0) do (

cls

echo.

type rest.txt

echo. 已经坐了45min啦，站起来走走吧！

echo. 倒计时数%%i后，再继续吧！

ping 127.1 -n 2 >nul

)

exit

pause
```
