2. 使用全局变量来保存Robot对象。在主控制器中创建Robot对象并将其保存在全局变量中：
```python
# 主控制器
from controller import Robot

robot = Robot()

# 在其他模块中，导入该模块并使用全局变量 robot
from main_controller import robot

# 在其他模块中，可以直接使用全局变量 robot，而不用再次创建 Robot 对象
print(robot.getName())
```
