假如我有多个py源文件，在webots里如何调用？
如果你有多个 Python 脚本文件，可以通过以下方式在 Webots 中运行它们：

打开 Webots，选择仿真世界和场景，然后在场景的根节点中添加 Supervisor 节点。
在 Supervisor 节点上右键单击，选择 “Add Controller” -> “Python” 来添加 Python 控制器。
在 “Python Controller” 对话框中，输入 Python 脚本的文件名，例如 my_controller.py。如果你有多个脚本文件，你可以在一个脚本文件中导入其他脚本文件，并在主脚本文件中运行它们。
单击 “OK” 来保存设置并启动仿真。
